# Problem Description

Norman Osborn has offered me a Senior Cyber Security Consultant role at Oscorp. He wants to design a comprehensive cyber security program for Oscorp that:

- Highlights current deficiencies in Oscorp's cybersecurity controls.
- Create a 3-year roadmap for oscorp to improve their cybersecurity posture.

## Current Oscorp Cybersecurity Team

- **Cybersecurity Analyst:** A generalist who responds to cyber incidents as they arise. Reports to Oscorp’s IT Manager.
- **Network Engineer:** Manages the firewalls. Reports to the Network Team Leader.
- **Cybersecurity Consultant:** Your new role at Oscorp. You will initially report to the IT Manager.

## Oscorp’s Current Cybersecurity Controls

- **Organisational Governance:**
    - The CEO has a clear business strategy.
    - Cybersecurity roles and responsibilities have not been defined and are assigned to the IT team.
    - There is no cybersecurity strategy.

- **Asset Management:**
    - The IT team maintains a spreadsheet containing laptop serial numbers.
    - The spreadsheet includes each machine’s model and warranty details.
    - Oscorp uses Microsoft Office 365 and relies exclusively on Software-as-a-Service (SaaS) applications.
    - All data is stored in Microsoft Azure cloud.
    - The IT team uses a Secure Operating Environment (SOE) to image all laptops with the latest Windows desktop version.

- **Business Continuity and Disaster Recovery:**
    - The IT team conducts regular disaster recovery testing.
    - The IT team has clear, documented business continuity plans.
    - The IT team takes regular backups and tests them periodically.

- **Vulnerability Management:**
    - Oscorp has purchased the Qualys vulnerability scanner.
    - The IT team uses Qualys on an ad hoc basis.
    - There is no formal vulnerability management programme.
    - Qualys reports a large number of high and severe vulnerabilities.

- **Risk Management:**
    - Oscorp has a risk team that performs financial risk activities.
    - There is no technology or cyber risk process at Oscorp.

- **Third-Party Risk Management:**
    - Oscorp does not perform third-party risk management.
    - Contracts are reviewed by Procurement and Finance, without IT involvement.

- **Identity and Access Management:**
    - Oscorp uses Microsoft Active Directory to manage users and groups.
    - There is no privileged access management solution.
    - The admin account password is shared among a few senior IT team members.
    - Access to resources is granted upon request.
    - The organisation does not use two-factor authentication for login.
    - Complex login passwords are used.
    - Employees use a VPN to log in remotely when required.

- **Network Security:**
    - The organisation has Palo Alto next-generation firewalls.
    - The firewalls have been configured by the network team.
    - The network team audits the firewalls annually.
    - The firewalls receive regular updates.
    - The IT team maintains up-to-date network diagrams, including the cloud environment.
    - The network is segmented using VLANs.

- **Physical Security:**
    - Oscorp is a highly secure facility with state-of-the-art CCTV cameras throughout.
    - Oscorp takes physical security very seriously.
    - All employees undergo extensive vetting.
    - Research labs and physical facilities are monitored 24/7.

- **Data Security:**
    - Oscorp does not have a Data Loss Prevention (DLP) solution.
    - All data resides in Microsoft Azure cloud and Microsoft Office 365.
    - A key critical application is a SaaS service provided by Horizon Labs.

- **Policy:**
    - There is one generic IT policy in place.
    - There is no formal information security policy.
    - There are no data governance policies or information classification.

- **Cybersecurity Detection and Response:**
    - There is no dedicated detection or response capability.
    - The IT team responds to alerts from Microsoft Defender antivirus.
    - There is no Security Information and Event Management (SIEM) solution.

- **Security Education and Awareness:**
    - All employees must complete an online induction training module.
    - The module includes basic cybersecurity instructions.

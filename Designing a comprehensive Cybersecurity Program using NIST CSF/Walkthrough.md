# Project Walkthrough

## Assessment Approach

For this project, I used the information provided in the Oscorp case study to assess the organisation’s current cybersecurity posture and identify gaps in its existing controls. I documented the assessment in an Excel workbook, using the NIST SP 800-53 security and privacy control catalogue as a supporting reference.

The workbook organises the assessment around five NIST Cybersecurity Framework (CSF) functions: **Identify, Protect, Detect, Respond, and Recover**.

## Assessment Structure

Each assessment entry includes:

- **Control objective:** The intended security outcome.
- **Control description:** The practice or requirement being assessed.
- **Assessment questions:** Questions intended to guide evidence gathering and discussions with relevant stakeholders.
- **Pass/Fail result:** An assessment of whether the control is met, based on the information available in the case study.
- **Comments:** Supporting observations, identified gaps, and suggested improvements.

## Post-Assessment: Findings and 3-Year Roadmap

Following the gap assessment, I prepared a report for Oscorp’s stakeholders outlining the identified cybersecurity gaps and a proposed three-year roadmap for addressing them. The roadmap translates the assessment findings into a phased plan to strengthen the organisation’s cybersecurity posture.
